# 🎓 Quiz Application

A simple and interactive Quiz Application built using **HTML, CSS, and JavaScript**. This project allows users to answer multiple-choice questions, track their progress, and view their final score with a result message.

## 📖 Project Description

This Quiz Application is a beginner-friendly JavaScript project designed to practice important concepts like DOM manipulation, arrays, functions, event handling, timers, and dynamic content updates.

The application displays multiple-choice questions with a countdown timer for each question. Users can select an answer, get instant feedback with correct and wrong answer highlights, and see their final score after completing the quiz.

## 🚀 Features

- 📝 Multiple Choice Questions
- ⏳ 15 Seconds Timer for Each Question
- 📊 Question Progress Bar
- ✅ Correct Answer Highlight
- ❌ Wrong Answer Highlight
- 🏆 Final Score Result
- 🔄 Restart Quiz Option
- 📱 Responsive Design
- 🎨 Modern Glassmorphism UI
